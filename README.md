# ໂສພານົວ · SOPHANUA

แบรนด์น้ำปลาแดกปรุงรส (ນ້ຳປາແດກປຸງລົດ) ขวด 350 ml นำเข้าและจัดจำหน่ายโดย **MVM GROUP** ขายในลาว

โฟลเดอร์นี้รวมงานทั้งหมดของแบรนด์: หน้าสั่งซื้อ เว็บแบรนด์ และวิดีโอโฆษณา

|---|---|---|
| หน้าสั่งซื้อ (หลัก) | https://sophanua.soudwin.dev | `order-page/` |

## 1. หน้าสั่งซื้อ (`order-page/`)

เป็นหน้าเดียวที่ให้ลูกค้าเลือกซื้อ **1 ขวด** หรือ **1 แพ็ก (12 ขวด)** ตอนกดเลือก ขวดในกล่องจะขยับจาก 1 ขวดเป็น 12 ขวด หน้าจะแสดงราคา แล้วลูกค้ากดปุ่มเดียวเพื่อสั่งทาง WhatsApp (ลูกค้ากรอก ชื่อ เบอร์ ที่อยู่ แล้วข้อมูลจะไปอยู่ในข้อความ WhatsApp ให้เลย)

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `sophanua-order.html` | **ไฟล์หลักที่แก้** มี HTML, CSS และ JS อยู่ในไฟล์เดียว (ไม่มี `<!doctype>` / `<head>`) |
| `build.py` | ห่อไฟล์หลักด้วย `<head>` ที่มี SEO, ไอคอน และรูปตอนแชร์ลิงก์ แล้วเขียนออกไปที่ `dist/` |
| `media/` | `bottle.webp` (ขวดพื้นใส), `mvm.webp` (โลโก้ MVM), `og.jpg` (รูปตอนแชร์), `icon.png`, `mvm-src.png` (โลโก้ต้นฉบับ) |
| `_headers` | การตั้งค่า cache ของ Cloudflare |
| `design-notes/` | รูปตัวเลือกดีไซน์ที่เคยเทียบกัน (แถบแดง และพื้นหลังกล่องขวด) |

### แก้ราคา / เบอร์ WhatsApp
แก้ใน `sophanua-order.html` ส่วน `<script>` ด้านล่างของไฟล์:
```js
var PRICE = { 1: 28000, 12: 300000 };   // ราคา (กีบ) 1 ขวด / 1 แพ็ก
var MAX = { 1: 24, 12: 10 };             // จำนวนสั่งสูงสุดต่อครั้ง
var WHATSAPP = "8562058436321";          // 020 58436321 แบบสากล ไม่มี +
```
ถ้าเปลี่ยนราคา ต้องแก้ข้อความที่พิมพ์ราคาไว้ตรง ๆ ด้วย ได้แก่ "ປະຢັດ 36,000 ກີບ", "ຕົກຂວດລະ 25,000 ກີບ" และรายการใน `FACTS`
และให้ลบป้าย "ຕົວຢ່າງ" (ราคาตัวอย่าง) กับกล่องข้อมูลร้านที่เป็นตัวอย่าง (`.trust`) ออกเมื่อได้ข้อมูลจริงแล้ว

### ดูในเครื่อง
```bash
cd order-page && python3 build.py && python3 -m http.server 8790 --directory dist
```
แล้วเปิด http://localhost:8790

### ขึ้นเว็บจริง (Cloudflare Pages, โปรเจกต์ `sophanua`)
```bash
cd order-page && python3 build.py && npx -y wrangler@4 pages deploy dist --project-name sophanua --branch main --commit-dirty=true
```
- ต้องล็อกอิน Cloudflare บัญชี `Passive1888@gmail.com` ก่อน (`npx wrangler@4 login`)
- โดเมน `sophanua.soudwin.dev` ผูกกับโปรเจกต์ Pages นี้ไว้แล้ว โดยใช้ DNS CNAME `sophanua` → `sophanua.pages.dev`
- **Cloudflare Access:** ทั้ง `*.soudwin.dev` ล็อกด้วย Zero Trust ไว้ แต่ได้สร้าง Access application ชื่อ `sophanua` ที่เป็น **Bypass / Everyone** ให้ `sophanua.soudwin.dev` แล้ว ห้ามลบ ไม่อย่างนั้นลูกค้าจะเจอหน้าล็อกอิน
- **ห้ามแชร์ลิงก์ `sophanua.pages.dev` ให้ลูกค้า** เพราะโดเมน `.pages.dev` (และ `.vercel.app`) โดนบล็อกในลาว ให้ใช้ `sophanua.soudwin.dev`

## กฎการออกแบบที่เจ้าของกำหนดไว้ (ต้องทำตาม)

- **ภาษาลาวเท่านั้น** ห้ามมีภาษาไทยหลุดในหน้าเว็บ (ฟอนต์: Noto Sans Lao / Noto Sans Lao Looped)
- **โทนทองเข้มบนพื้นดำอย่างเดียว** ไม่มีโหมดสว่าง และไม่มีปุ่มสลับธีม
- **ต้องมีแถบแดงเลื่อน "ໂສພານົວ · SOPHANUA"** ใช้ตัวหนังสือแบบฝาขวด: ລາວ ไม่มีหัว เอียง + SOPHANUA ตัวโปร่งแบบเส้นขอบ
- กล่องโชว์ขวด: **ไม่มีถาด ไม่มีพื้นหินอ่อน ไม่มีเงาสะท้อน** พื้นหลังเรียบ
- ท่าทางขวด: ไม่มีการจางแบบครึ่งโปร่งใส (เคยดูเหมือนเงาซ้อน) แพ็กจะกางออกจากด้านหลังขวดหลัก ส่วนตอนโหลดหน้า ขวดต้องอยู่ตรงกลางเลย **ไม่ลอยเข้ามา**
- การ์ด "ຂວດລະ 350 ml" เล็ก ๆ มุมขวาบน
- มุมซ้ายบน: โลโก้ MVM + ตัวหนังสือ "MVM GROUP" | ໂສພານົວ
- ท้ายหน้า: "ນຳເຂົ້າ ແລະ ຈັດຈຳໜ່າຍໂດຍ MVM GROUP" + ชื่อบริษัทเต็ม "ບໍລິສັດ ເອຶມວີເອັມ ທີ່ປຶກສາ ແລະ ການຄ້າສາກົນ (ຂາອອກ-ຂາເຂົ້າ) ຈຳກັດ" (สะกดตามที่เจ้าของให้มา)
- สั่งซื้อด้วยปุ่มเดียวไป WhatsApp โดยมีฟอร์มสั้น ๆ 3 ช่อง (ชื่อ เบอร์ ที่อยู่)
